Sightline is a mobile app that helps people with vision disabilities navigate environments. This software uses image detection YOLO models to detect the presence of signs. The signs that this software can detect include traffic light signs, walk signs (on or off), crosswalk signs, exit signs etc. Upon detecting a sign, the software utilizes the size of the bounding box relative to the entire image to predict the user’s distance from the sign. The software then announces the sign, its distance away from the user, and its direction (left or right). This will allow vision-impaired people to exit unfamiliar buildings with the announcement of exit signs and walk through streets with the announcements of walk signs turning on and the locations of pedestrian road crossing. Additionally, Sightline could also help the user navigate to specific locations. The software allows users to speak into their phone of a location they want to go to. All the places associated with this location near the user’s location will then be listed out. For example, if the user says “library”, Sightline would list out all libraries in the area for the user to pick. Upon picking a specific location, the software will give walking directions to the user’s intended location. This software ultimately helps vision-impaired navigate environments as the sign detection and path routing features could be used in partnership with each other. For example, if the user is in a school and they want to go to the library, the software will first prompt the user to look for an exit in their current building. The user could then locate the exit with the software’s sign detection for exit signs. After that, the user could walk towards their intended location with the software giving them audio directions to “turn right”, “turn left”, or “keep walking straight”. If the user arrives at a crosswalk, the software will prompt them to wait until the walk sign is on and notify them once it is.
